Eng Math 10M
State and prove De Moivre's Theorem. Apply it to find the nth roots of unity.
Hint: (cosθ + i sinθ)^n = cos(nθ) + i sin(nθ). For roots, use θ + 2kπ and set n as fraction.
Eng Math10M
Solve a system of linear equations using Cramer's Rule and Matrix Inversion Method.
Hint: Cramer's: x = Dx/D, y = Dy/D. Inversion: X = A^(-1)B where A^(-1) = adj(A)/|A|.
Eng Physics10M
Explain principle, construction, and working of He-Ne Laser with energy level diagram.
Hint: Ratio 10:1 (He:Ne). Excitation of He, energy transfer to Ne via collision, population inversion in Ne, emission at 632.8 nm.
Eng Chem10M
Explain EDTA method for determining total hardness of water with chemical equations.
Hint: EBT indicator forms wine red complex with Ca/Mg. Titration with EDTA replaces EBT, turning solution blue. pH ~10 maintained by buffer.
C Prog10M
Write a C program to multiply two 3×3 matrices with input validation.
Hint: Use 3 nested loops (i, j, k). c[i][j] += a[i][k] * b[k][j]. Initialize result matrix to 0.
EDC10M
Explain Full Wave Bridge Rectifier. Derive efficiency and ripple factor expressions.
Hint: Uses 4 diodes. Efficiency = 81.2%. Ripple factor = 0.482. Vdc = 2Vm/π.
Elec Tech10M
State and prove Maximum Power Transfer Theorem for AC circuits.
Hint: Z_load must be the complex conjugate of Z_thevenin (R_L = R_th, X_L = -X_th). P_max = V_th^2 / 4R_th.
Digital10M
Draw and explain internal architecture of 8085 Microprocessor.
Hint: ALU, Accumulator, General purpose registers (B,C,D,E,H,L), Program Counter, Stack Pointer, Instruction Decoder, Timing & Control.
Comm Sys10M
State and prove Sampling Theorem. Explain aliasing and prevention.
Hint: fs ≥ 2fm. Aliasing occurs if fs < 2fm, causing spectral overlap. Prevent with anti-aliasing low-pass filter before sampling.
Control Sys10M
Determine stability using Routh-Hurwitz criterion for a given characteristic equation.
Hint: Form Routh array. System is stable if all elements in the first column have the same sign. Sign changes = roots in RHS.
Power Elec10M
Explain construction, working, V-I characteristics of SCR. Define latching/holding current.
Hint: 4-layer PNPN device. 3 junctions. Forward blocking, forward conduction (avalanche at V_BO or via gate pulse), reverse blocking. Latching > Holding.
Power Elec10M
What is a chopper? Explain Step-up and Step-down choppers with output voltage derivations.
Hint: DC-DC converter. Step-down: Vo = D*Vs. Step-up: Vo = Vs / (1-D). Where D = duty cycle = Ton/T.

🧑💻 C Programming Lab

▼

Core Experiments:

  • Reverse a string and check palindromes without library functions
  • Implement sequential and binary search algorithms

Viva Questions:

Q: Difference between structure and union in memory allocation?
A: Structure allocates separate memory for each member. Union allocates memory equal to largest member — all share same location.
Q: Why is dangling pointer dangerous and how to avoid it?
A: After free(), pointer still points to deallocated memory. Set pointer = NULL immediately after free().

🔲 Digital & Microprocessor Lab

▼

Core Experiments:

  • Verify truth tables for all basic and universal logic gates
  • Design Half Adder and Full Adder using logic gates
  • Interface 8255 PPI with 8085 kit to blink LEDs

Viva Questions:

Q: Why are NAND and NOR gates called universal gates?
A: Any Boolean function can be implemented using only NAND or only NOR gates.
Q: Function of ALE (Address Latch Enable) pin in 8085?
A: ALE goes HIGH to indicate that AD0–AD7 carry lower 8 bits of address, allowing external latch to save it.

📡 Communication System Lab

▼

Core Experiments:

  • Observe and calculate modulation index of AM signal using Oscilloscope
  • Generate and demodulate FM signal using ICs
  • Study PAM and PWM signal generation

Viva Questions:

Q: What happens if AM modulation index exceeds 1 (overmodulation)?
A: Causes envelope distortion and clipping of carrier, leading to bandwidth spreading and severe distortion at receiver.
Q: Standard Intermediate Frequency for AM and FM receivers?
A: AM IF = 455 kHz. FM IF = 10.7 MHz.

⚙️ Control System Lab & ⚡ Power Electronics Lab

▼

Control Systems Viva:

Q: Physical significance of damping ratio in second-order system?
A: Determines response shape. ζ=0: undamped. 0<ζ<1: underdamped. ζ=1: critically damped. ζ>1: overdamped.

Power Electronics Viva:

Q: Methods to turn off (commutate) an SCR?
A: Natural Commutation (AC reversal) and Forced Commutation (LC circuits, Class A-D).
Q: Why is DIAC connected to TRIAC gate in dimmer circuits?
A: DIAC provides a sharp triggering pulse regardless of polarity, ensuring symmetrical firing in both half cycles.
